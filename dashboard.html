Survivors Network

A survivor-controlled project for private information, independent access, and practical support resources.

Welcome

Survivors Network is being developed around individual control of personal information. Its goal is to provide a comfortable and accessible environment for organizing information and finding useful resources.

Local control

The local application is designed to run on an individual's own computer. Private records are not intended to be stored in a centralized public database.

GitHub provides the software and documentation. It is not the private records repository.

Get the application

Download the project source and follow the installation instructions in the README.

Visit GitHub

Privacy and safety

Local encryption is one layer of protection. It cannot guarantee protection against a compromised computer, monitoring software, or access to an unlocked device.

Project development

The project is designed as a modular system. Future development includes independently operated components, peer communication, resource verification, and controlled information synchronization.
